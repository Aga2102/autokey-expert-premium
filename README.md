# AutoKey Expert Premium

Nowoczesna strona typu one-page zbudowana w Next.js 15 i Tailwind CSS. Obejmuje responsywny landing page, rozwijane FAQ, demonstracyjny formularz, przyklejone menu i automatycznie przygotowane podstrony marek (`/marki/audi`, `/marki/bmw` itd.).

## Start lokalny

1. Zainstaluj Node.js 20 lub nowszy.
2. W katalogu projektu uruchom `npm install`.
3. Uruchom `npm run dev` i otwórz `http://localhost:3000`.

Przed publikacją zastąp numer telefonu, e-mail, lokalizację/mapę oraz podłącz formularz do wybranej usługi wysyłki wiadomości.
